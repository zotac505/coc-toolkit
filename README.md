# CoC Toolkit (クトゥルフTRPG プレイ＆セッション総合支援Webアプリ)

クトゥルフ神話TRPG（第6版・第7版）のプレイヤー（PL）およびキーパー（KP）のための総合支援Webサイトです。
サーバー不要（完全ブラウザ動作）で動作し、**GitHub Pagesを使って完全無料で全世界に公開**できます。

---

## 🎲 主な機能

### 1. キャラクター作成 ＆ 管理（キャラクリ）
- **6版 / 7版 切り替え対応**: ステータス・計算式（HP/MP/SAN/DB/ビルド/移動率など）を瞬時に切り替え
- **能力値一括ダイスロール**: ルールに基づいたランダム生成、個別振り直し
- **技能ポイント自動計算**: 職業技能P・趣味技能Pの残りポイントと配分をリアルタイム可視化
- **バックストーリー生成**: 外見、信念、大切な人、意味のある場所、癖などのランダム自動提案
- **ココフォリア（CCFOLIA）駒ワンクリック出力**: クリップボードにコピーしてココフォリア盤面にペーストするだけで、能力値・ステータス・チャットパレットが揃ったコマを即時召喚
- **データ保存・持ち運び**: LocalStorage自動保存、JSONエクスポート／インポート

### 2. シナリオ集 ＆ 閲覧・作成（KPモード）
- **シナリオギャラリー**: 初心者向けクローズド・シティシナリオを事前収録
- **検索・フィルター**: プレイ時間、人数、舞台（現代日本/洋館等）、ロスト率での絞り込み
- **KPモード（ネタバレ防止アコーディオン）**:
  - 「真相」「怪異の正体」「ギミック」をクリックで開閉
  - セッション中にワンクリックで描写テキストをクリップボードコピー可能
- **ハンドアウト（HO）管理**: 公開情報と秘匿（秘密）情報の個別開閉
- **オリジナルシナリオ執筆**: ブラウザ上でシナリオを作成し保存・JSON配布可能

### 3. KP（キーパー）セッション支援ツール群
- **SANチェック ＆ 狂気判定計算機**:
  - 現在SANと減少値から、一時的狂気（5以上減少）／不定の狂気（1/5減少）を自動警告
  - 短期狂気表（1D10ラウンド）、長期・不定の狂気表（1D10×10時間）、恐怖症・マニアのワンクリックロール
- **戦闘ラウンド管理（DEXイニシアチブ）**:
  - 探索者とエネミーのDEX順自動ソート、手番ハイライト、HP・状態追跡、ターン進行
  - 保存済みキャラクターからワンクリックで戦闘に参加可能
- **多機能ダイスボット**:
  - 1D100ロール（クリティカル、スペシャル、ハード、イクストリーム、ファンブルの自動判定）
  - シークレットダイスモード（KPのみ確認可能）
  - 履歴ログ（直近30件）
- **ハンドアウト（HO）配布テキスト整形**:
  - 公開情報・秘密情報をPLごとの個別チャット送信用にワンクリック整形コピー
